# Moreton Bay Community Wealth and Mutuals

A plain-English public website exploring community wealth funds, mutual protection, Indigenous data sovereignty, Native Title pathways, and everyday community choices for the Moreton Bay archipelago.

The audience is non-technical everyday Australians, including multicultural families, First Nations people, volunteers, organisers, Elders, teenagers, and local groups who need simple language before they need legal detail.

## What is inside

- `index.html` starts the doorway.
- `wealth-funds.html` explains future funds and community sovereign wealth.
- `mutual-care.html` explains insurance, discretionary mutual funds, and mutual protection.
- `data-sovereignty.html` explains personal, household, community, and Indigenous data sovereignty.
- `country-deals.html` explains Native Title, Indigenous Land Use Agreements, royalties, co-ownership, and seven-generation wealth.
- `choose-a-path.html` offers practical starting options.
- `source-trail.html` lists archive and official source trails, plus open questions.

## Local preview

Open `index.html` in a browser. This is a static site, so it does not need a build step.

## Source posture

This site is a research doorway. It is not legal, financial, cultural, insurance, taxation, or investment advice. Any real-world fund, mutual, insurance product, Indigenous Land Use Agreement, data governance model, or token-like system needs proper community authority and qualified professional advice.
